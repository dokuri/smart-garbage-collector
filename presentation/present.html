🤖 Route Optimization Algorithm

Algorithm: Greedy Nearest Neighbor + 2-Opt Improvement

Step 1

Calculate urgency for each location

Step 2

Score each route A, B, C

Step 3

Select highest score route

Step 4

Optimize collection order

Formula: Score = (avg_risk × 0.6 + urgent_count × 20) / (1 + distance × 0.02)

Higher score = better route
